# 戦闘HUDとタッチ操作

2026-10-22。Geminiからの視認性・誤操作防止の提案を受け、既存のHP表示、円形クールダウン、操作カスタマイズ、拡張タップ判定を強化した。攻撃・敵・回復量・再使用時間・当たり判定など、戦闘ルールは変更していない。ユーザー所有の `swordsman-game.zip` は変更していない。

## 表示

- HP 30%以下で薄い赤の画面縁と足元の輪郭を継続表示。点滅を切った設定と動きを減らす設定では一定の薄さを保つ。演出・メニュー中は表示しない。
- 主人公付近に既存のHPバーと「回復 ×個数」を表示。ボタンやボスのHP・術式バーを避け、横画面では上や横に移す。緊急時には通常操作のチュートリアル文を抑え、生存情報を優先する。
- 回復薬は「回復可／満タン／空／待機秒数」を区別。HP 55%以下、または技のMPが足りないときに使用可能な回復薬を淡い緑で強調。空や待機中は回復を促さない。
- 技・回避は残り秒数と明るい外周の円形ゲージ。技名を消さず、使用可能な状態は枠で示す。MP不足は青い表示と言葉で伝え、文字全体の透明度を落とさない。無料の反撃と溜め中の予約MPも考慮する。
- 画面縁のグラデーションは寸法と描画解像度ごとに再利用。継続表示用のパーティクルは生成しない。

## タッチ操作

- 回避76×60 CSS px、回復薬58×60 CSS px。縦横の基本配置に収め、手動のサイズ調整も維持。
- 設定の最初に左右の基本配置を用意。選択中の配置を示し、保存するまでは元の設定を上書きしない。従来のドラッグ・大きさ・濃さ・左右反転・縦横別保存は維持。
- 通常の操作は8px、回避・回復薬は10pxまで外側の押しずれを補助。近い操作を選び、1.5px未満の差しかない曖昧な中間は発動させない。無効なボタンも周囲の領域を占めるため、空の回復薬を押そうとして別の技が発動することを防ぐ。
- ブラウザの直接タップとポインターキャプチャを優先し、スティックの指を保持したまま別の指で技を押せる。

## 検証

ローカルChromiumで検証。物理スマホでの確認ではない。

- `node tests/combat-readability.cjs`：HP・MP・回復薬・クールダウン21項目、判定領域の所有32項目、縦横4サイズ（320×568、390×844、568×320、844×390）の左右配置・重なり・タップサイズ、保存・取消・再読み込み、実際の二本指によるボタン外側5pxの技入力と移動継続、スティックの中央復帰。主人公付近の情報が操作ボタンを覆わないことも検証。
- `node tests/startup.cjs`：通常・旧ブラウザ相当・JavaScriptなし・Canvasなしの起動。
- `node tests/signature-touch.cjs`、`node tests/dark-fantasy.cjs`：実際の同時操作、溜め・発動・移動再開、縦横の操作範囲と既存の戦闘。
- `node tests/sovereign-trials.cjs`：95項目のボス・術式・状態異常・追跡・巨人の大剣・保存互換、縦横のボスUI。
- `node tests/forged-edition.cjs`：69項目の既存仕様、縦横6サイズの地図・準備・報酬、操作のドラッグ・サイズ・濃さ・左右反転・縦横別保存と再読み込み。
- `node scripts/measure-touch.cjs --trials --survival`：HP 25%から、神・影の詠唱と視界狭窄・毒、自動技・手動技、危険時のHUDを重ねて測定。DPR 2、準備30フレーム＋計測180フレーム。処理時間p95は神4.2ms・影4.3ms、フレーム間隔p95は双方33.4ms、エフェクト最大127/197（上限200）。クラウドChromiumの値であり、実機の速度を保証する数値ではない。記録は `combat-readability-performance.json`。
- `node scripts/build.cjs --check`、`git diff --check`：ソースからの配布HTML再生成と差分確認。
