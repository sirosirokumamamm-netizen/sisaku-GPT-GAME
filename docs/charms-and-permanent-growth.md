## お守り

表示上の「護符」を「お守り」に統一。旧3品のIDと購入・装備状態は保持。装備は1個で、出発した挑戦に装備内容を固定する。中断保存にもその装備を記録し、再開後にプロフィールの装備へ差し替わらない。

発動は各区画の戦闘開始に1度。通常区画は初回の敵出現時、ボス区画は登場演出終了時。増援、変身、休憩の開き直しでは再発動しない。ボス再挑戦は戦闘前のスナップショットへ戻る。神殿の事前技選択では発動しない。

|---|---|---|---|
|若葉|最初から / 600 G|毎区画|HP8%、最低6回復|
|清泉|草原クリア / 650 G|毎区画|MP12%、最低3回復|
|清浄|水路クリア / 900 G|毎区画|その区画で状態異常を1回防ぐ|
|岩守り|火山クリア / 1100 G|毎区画|最初のHP被弾3回を6軽減、最低1ダメージ|

回復は最大値まで。無敵、回避、受け流し、バリアによる完全防御では軽減回数を使わない。回避した状態異常や既存の異常再付与保護でも、お守りの異常防御回数を使わない。残り回数は戦闘画面に表示する。

よろずやは専用のイラスト棚と選択詳細を用意し、効果と発動条件を分けて表示する。購入・装備は詳細の明示ボタンで確定。棚だけをスクロールし、購入と戻るボタンは常時操作できる。出発画面はよろずや・ミッション・鍛錬場を並列に配置。スマホ縦画面では出発ボタンを独立した下段へ置く。

## 永続ステータス

ミッションの既存HP・MP報酬を2倍（HP2→4、MP1→2）にし、攻撃力・属性威力4%、守備力2の報酬を対象ミッションへ追加。すでに受け取ったミッションもIDから合計するため、新しい効果が次の冒険から適用される。受取済みのゴールドは再配布しない。全対象ミッションの合計はHP12・MP4・攻撃力／属性威力8%・守備力6。報酬詳細とまとめ受取の通知にも表示する。

鍛錬場「支度」には生命・魔力・剛刃・堅守を追加。各5段階で、1段階につきHP8・MP2・攻撃力／属性威力4%・守備力2。技巧石を使用し、ゴールドを代用しない。生命・魔力の費用は35 / 65 / 105 / 160 / 230、剛刃・堅守は50 / 90 / 145 / 220 / 310。最大強化にはそれぞれ595石、815石必要で、装備単品の鍛錬より多め。専用のハート・雫・剣・盾のイラストと現在→強化後の値を表示する。

既存の装備・継承技の永続＋効果も1段階3%→6%、必殺技4%→8%へ変更。Lv.UPや技そのものの基礎値は変更せず、＋の増加分を2倍にする。表示と戦闘中の計算を同じ係数へ合わせ、技の1ヒット上限は維持する。保存・再開では既に適用した能力を二重加算しない。

## ゴールド

初期ステージの獲得水準を保ち、表示順に通常入手倍率を1 / 1.04 / 1.08 / 1.12 / 1.18 / 1.22 / 1.32 / 1.42 / 1.5へ調整。既存の基礎係数0.94・金運の効果・端数繰越を維持する。武器の価格・100 Gのおすすめセール・ミッションの一度だけの受取は維持。

敵数の少ない神殿は、各決闘のクリア時に基礎額360＋区画番号×60 Gを追加。入手倍率を適用し、ポーション支給と同じ区画記録で二重支給を防ぐ。最終区画も対象。敗北と再挑戦の精算は既存の差分払いを維持する。目標達成と強敵撃破の表示も、倍率適用後の実際の入手額を示す。

## 技の方向補助とボス

ボス区画の手動技は、近くの通常敵よりボスを優先して向きを合わせる。溜め技は開始時と放つ直前に補正する。自動技・移動入力は従来どおり。範囲技の射程は延長せず、ダーククラッシュと地面指定技は実際の射程内で対象を決める。

神の第1形態は、全体攻撃の予兆中まで障壁を維持し、攻撃が実際に解決した直後に5.5秒間解除。時間切れだけでは解除しない。短い静止と2.8秒の予兆を合わせて約3.3秒の障壁を基本にする。他の攻撃の解決待ちがあれば前後する。障壁中は全命中1、解除中は通常ダメージ。既存の鏡演出と色の違いを残し、解除の文字と光を追加。第2形態の障壁周期は維持する。

忘却の王は、予兆中にも側面へ回り込み、間合いを詰める。通常移動500 / 650、短い加速中900 / 1150を第1・第2段階の目安とし、予兆中は80%で移動。攻撃待ちは1.25 / 0.85秒から0.32 / 0.18秒、後隙は1.4秒から0.42 / 0.28秒へ短縮。通常予兆は第1段階0.65〜0.85秒を基準とし、第2段階はその78%。全体攻撃は2秒 / 1.56秒で、安全地帯と回避を維持。足元の砂塵で加速を見せ、攻撃ポーズのタイマーも進める。HPと攻撃力は据え置き。

## 追加：影の大魔王と黎明の大剣

影の大魔王の基本HPを15500→22000へ引き上げ。復活時の既存スケール1.18倍・HP75%回復は維持。第1形態は6種類、第2形態は10種類の攻撃へ拡張し、通常の攻撃間隔も2.45 / 2.05秒から1.55 / 1.2秒へ短縮。第2形態の猛攻は11秒、反撃窓は2.6秒へ変更。既存の足跡攻撃、輪舞、交差斬り、葬列も範囲・速度・威力を強化する。

従来の視覚的な残像に加え、HPを持って独立攻撃する分身を最大3体、遊撃兵・術師などの近衛を最大4体召喚する。プレイヤーから離れた位置で約1秒かけて出現し、分身はボスに似た姿と「分身」表示・HPバーで区別する。分身の攻撃予兆は、ボスの強攻撃と同じく表示対象。第1形態の分身はHP1400、第2形態はHP2000。召喚体は45秒で消え、召喚主の撃破でも消える。経験値とゴールドを出さず、召喚体による無限稼ぎを防ぐ。上限に達した召喚手段は次の攻撃へ進み、空振りの待機時間を作らない。

「葬月の檻」は追跡する墓印と、少し移動した場所を安全地帯とする全域の輪を重ねる。墓印は発動0.35秒前に追跡を止め、輪には1.5秒の予兆・半径125の安全地帯を残す。攻撃自体が実際にダメージを与えることを確認し、色のついた予兆・斬撃・召喚演出を付ける。

黎明の大剣は範囲内の距離に応じて、根元120%→中央100%→先端80%へ連続的に変化する。通常版は現在の範囲を基準にし、改は描かれる大剣の半径620を基準にする。改の射程無制限は維持し、620より遠くは80%を下限とする。敵の弱点・会心・既存の威力上限はこの後に適用する。選択画面の表示を「中央威力」、鍛錬の表示を「中央の基礎威力」として基準を明示する。
