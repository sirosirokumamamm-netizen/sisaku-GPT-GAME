# 王たちの試練とボスの追跡

2026-10-22。既存の保存形式・技ID・インベントリ・過去のランク記録を維持。配布はビルドで生成した `index.html` 一つ。ユーザー所有の `swordsman-game.zip` は変更していない。

## 戦闘の変更

- 巨人の大剣：攻撃力430・振り速度32%は維持。間合い165%→280%、歩行82%。回避は通常速度。技は従来どおり武器と技の間合いの中間値。中断セーブの射程は獲得強化を残し、一度だけ移行する。
- 小幅な威力調整：飛翔剣34→32、守護の双刃13→12、Lv.3ダーククラッシュ460→435、Lv.3黎明の大剣・改560→520。改のLv.3は従来の旧Lv.3の460を上回る。
- ランク：舞台別の時間基準130/160/190/225/280/300/370秒。クリア・被ダメージ比率・時間・少量のジャスト回避加点で評価。Sは被弾5回以内・被ダメージが最大HPの45%以下も必要。未クリアはA/Sにならない。過去のランクは下げない。
- 第二形態の最大HP：魔王7670、神8584、影葬王12036。変身時は新上限の75%に回復し、従来の上限超過ポーションを1個支給。
- 神は第一形態の衣と小さな光輪から、第二形態の翼・宝珠・多重光輪へ変貌。七連の追尾雷、六方向の光剣、しびれの波を追加。速い動きに短い静止を挟み、攻撃できる機会を確保。
- 魔王は魔術から剣による突進・薙ぎ払いへ。第二形態に三段断頭斬・攻撃力低下・毒を帯びた噴火を追加。影葬王は毒霧・暗幕・三連の残影狩りを追加。通常時の長い完全無敵を強いダメージ耐性へ変更し、猛攻中も少しずつ削れる。

## 大技と状態異常

神・影葬王の第二形態は初回12/14秒後、その後一定間隔で詠唱を始める。神10秒・術式830、影11秒・術式860。敵HPの下のバーを削り切ると3.4秒の隙ができる。詠唱中は敵HPにダメージが通らず、あらゆる攻撃が術式を削る。失敗はHP 1。毒と保留ダメージを解除し、2秒の保護を設ける。プレイヤーの攻撃予約を詠唱開始で取り消さない。選択画面・一時停止・カットイン中は戦闘時間が進まない。

毒は5秒（1秒ごとの小ダメージ）、視界狭窄と攻撃力半減は4秒、しびれは最大0.42秒で連続拘束を抑制。回避でしびれを抜けられる。状態異常のみの広域攻撃は約0.64秒予兆・直接ダメージ0で、回避・無敵・受け流しで防げる。毒つき通常攻撃は実際の被弾後に適用し、遅延回避や完全防御なら毒も防ぐ。区画休憩と登場・変身の終了で解除する。効果色・身体の表示・残り秒数を用意し、視界狭窄中も操作UI・予兆・安全地帯・主人公の輪郭は読める。

## カメラと表示

ボス戦中のみ、ボスと入力方向へ小さくカメラを寄せる。横は画面幅の7.5%、縦は高さの4.5%相当まで。ズーム・敵の当たり判定・攻撃力・速度は方向表示の追加では変えない。画面外は矢印・名前・距離で追跡し、横の短い画面では上部の空きスペースへ。操作配置を変えたときもボタンの領域を避ける。描画中のDOM測定は行わず、操作配置更新時に位置を記録する。
