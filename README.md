# 蒼刃の剣士

北へ進み、群れを斬り、見切り回避から反撃するブラウザ用アクションローグライト。
HTML・CSS・JavaScript、描画と音の生成を **index.html 1ファイル**に収めています。ゲームの実行に外部画像、ライブラリ、ビルド、通信は必要ありません。

## 起動

`index.html` をブラウザで開いて「剣士の冒険へ」を押します。HTTPで開く場合：

```sh
python -m http.server 8000 --bind 0.0.0.0
```

## 2.5Dと10ステージ

地面を奥行き方向に圧縮し、人物を立たせる正投影の2.5D描画です。ひし形の操作座標ではありません。
岩・壁・水晶・炉に上面、側面、高さと影を描きます。主人公が障害物の後ろに入ると手前の障害物が薄くなります。
主人公は画面の下寄り（PC70%、スマホ67%）に置き、前方を広く見せます。HPバーは画面上で一定の大きさです。
描画と画面外の敵表示・増援判定は同じ奥行き係数を使います。

| ステージ | 地形・戦闘の特徴 | 任意目標 |
| --- | --- | --- |
| 陽だまりの草原 | 群れと基本の剣技。行動に合わせて操作案内 | 1回の技で3体撃破 |
| 翡翠の石橋 | 深い川と橋、突進する敵、盾役 | ジャスト回避1回 |
| 蒼羽の森 | 遮蔽物と浅瀬、射手と支援役 | 支援役2体撃破 |
| 朱の古城門 | 火薬樽の連鎖、第二陣に強敵 | 樽2つを爆発 |
| 月影の闘技場 | 中ボスとの一対一、登場演出 | ボスの隙に技2回命中 |
| 水晶の峡谷 | 水晶柱で弾を防ぎ、盾の背後へ | 背後攻撃3回 |
| 熾火の鍛冶場 | 炉の遮蔽と連鎖しやすい樽、爆弾役 | 1回の技で5体撃破 |
| 嵐の庭園 | 左右の射手と混成部隊 | ジャスト回避2回 |
| 星降る回廊 | 前後から迫る包囲網 | 1回の技で5体撃破 |
| 結晶の祭壇 | 二段階のボスと反撃の隙 | ボスの隙に技3回命中 |

任意目標は各ステージで一度だけ40G・MP3を獲得。未達でも進行できます。
右上のSTAGE表示から全10ステージの現在地と攻略のヒントを確認できます。

岩・石壁・水晶柱・炉は移動と物理弾を遮ります。川は橋で渡り、浅瀬では移動が少し遅くなります。火薬樽は周囲の敵と敵弾に作用し、主人公を巻き込みません。
敵は16単位の経路探索を使い、体の大きさに合った通路を選びます。出現点は障害物と主人公からの距離を考慮して分散します。

## 戦闘の手応え

予兆は全攻撃で「範囲が満ちると発動」に統一。円・リング・直線・扇形を実際の判定と同じデータから描き、発動した瞬間に同じ形を白く光らせます。射手とボスの扇状弾は弾道も表示します。

移動速度は元の毎秒205。攻撃中も速度を落としません。ボタンの連続入力を整理する待ち時間は約0.09秒です。自動技の命中では動きを止めません。敵は移動先を予測して狙い、横から回り込むため、連打しながら円を描くだけでは攻撃を避けきれません。出現位置は左右、前後、包囲、交差などの配置から抽選します。

通常攻撃は基礎威力13・間隔0.43秒。最初の「蒼月斬」は威力34・MP不要・再使用2.2秒です。
剣の振り抜き、体の踏み込み、敵のよろけ、倒れた敵の消滅、方向に応じた斬撃音を表示します。通常、強打、会心、ボス撃破で衝撃に強弱があります。

- 再使用直前の短い先行入力と、回避終了から技への入力を受け付けます。
- 回避は短いステップ。再使用0.95秒・無敵0.28秒。
- 攻撃直前の回避で敵が1.25秒間スローに。剣士は通常速度です。
- ジャスト回避でMP5回復、技の再使用をリセット。次の技は威力2倍・MP不要。
- 盾役は正面を防御し、背後と攻撃直後が弱点です。
- 支援役は周囲の敵の攻撃力を強化。倒すと強化が止まります。
- 同時に主人公を狙う通常敵の予告数を抑えています。

第一陣を半分以上倒し、画面内の敵が初期数の約3割（最低2体）以下になると増援を予告。0.65秒後に第二陣が生き残りと合流します。全滅時にも増援が来ます。通常の敵は出現直後の約1秒間、攻撃も被弾もせず、出現位置を確認できます。
通常戦の全滅後は0.8秒、ボス撃破後は1.4秒の決着の時間を取り、その後に休憩画面を開きます。

## 成長・技の進化

経験値が必要量までたまると即レベルアップします。撃破の演出を0.22秒見せてから、重複しないランダム4択を開きます。
必要経験値は最初24、以降約1.45倍。レベルアップで最大HP＋6。HP6の回復分は戦闘後に受け取ります。

候補は操作する技20種類、自動発動4種類、休憩用1種類、常時強化15種類の合計40種類。現在の技の強化と、同じ系統の候補も組み込みます。空き枠があれば新しい技を最低1つ含めます。最大Lv.3を除外し、再表示による引き直しを防ぎます。
新しい操作技を選ぶと、空きスロットへ自動装備します。満杯ならJ・K・Lと同じ色の3枠から入れ替え先を選びます。「今の装備を使う」で見送ると習得だけを行います。入れ替え画面はJ・K・Lまたは1・2・3キー、見送りはEscでも操作できます。戦闘後の任意の装備変更・回復と、毎回の休憩時の確認も維持しています。「癒しの光」は戦闘用の枠へ装備せず、休憩画面で使えます。

技は威力・回復量、再使用秒数、消費MPを比較表示します。範囲は「広範囲」「遠くまで貫通」などの表現です。
蒼月斬、連鎖雷、紅蓮の吸命剣、氷華円舞、飛翔剣、蒼鋼の護りには、追加斬波・全周囲反撃・追加落雷・出血・多方向斬撃・押し返しなどの進化があります。

同系統の習得段階の合計3・6で相乗効果が発動します。

| 系統 | 3段階 | 6段階 |
| --- | --- | --- |
| 剣舞 | 5回命中で追撃の斬波 | 斬波の威力・範囲が増す |
| 雷鳴 | 攻撃技に追加の雷 | 威力が増し、もう1体へ連鎖 |
| 紅蓮 | 攻撃技で炎上、撃破時に爆発 | 炎上・爆発が強化 |
| 見切り | ジャスト回避でバリア | バリア強化と戦闘後のHP回復 |

相乗効果には発動間隔があり、自分自身から無限に追加攻撃を発生させません。

## 自動発動する既存の技

既存の「守護の双刃」「星の相棒」「蒼鋼の護り」「剣気解放」をスロット不要に変更しました。習得後、戦闘中に敵が近いと自動発動し、MPを使いません。発動間隔と強化の効果はあります。装備欄へは入らず、緑のアイコンに状態を表示します。習得済みの自動技は戦闘後の装備画面でも一覧できます。

## 流派・回復・商店

開始時に3つの流派を選べます。初期の技は蒼月斬1つです。

| 流派 | 初期能力 |
| --- | --- |
| 蒼月の型 | HP90・MP24、基本形 |
| 雷光の型 | HP80・MP30、MP回復が少し速い |
| 堅守の型 | HP108・MP20、被ダメージを1軽減 |

MPは最初から毎秒0.35（雷光は0.55）回復。常時強化でも増やせます。
ポーションは初期1本、最大3本。HP45・MP12を同時に回復します。価格80G、商店の在庫は各ステージ2本。使用・購入は戦闘後の休憩中のみです。購入して持つ／その場で飲むを選べます。
通常戦後は最大HPの約16%、ボス戦後は約30%とMP7を回復します。レベルアップ・吸命などのHP回復も戦闘後に受け取ります。新しい面に進む前に、毎回装備変更の有無を確認します。

## ボスと結果

ボスは踏みつけ、内側が安全な衝撃波、十字攻撃、扇状弾を使います。HP半分で覚醒し、予告時間が変化。攻撃後の「反撃の隙」は与ダメージが1.25倍になります。5面と10面はボスだけが出現し、増援・取り巻きはありません。「ボス出現！」の演出中は操作と敵の動きが止まります。通常時の与ダメージは0.65倍、攻撃後の反撃中は1.25倍で、隙を狙うほど効率が上がります。10面を突破し、最後の休憩画面から結果へ進むとクリアです。

結果は総合スコア、S〜Dランク、タイム、前回との差、自己ベスト、回避・連鎖・任意目標・被弾・相乗効果回数を表示します。

- 討伐×100、経験値×4、獲得ゴールド×5、突破×1,000。
- ジャスト回避×100、最大連鎖×25。
- 全クリアで10,000。6分以内は残り秒数×20。
- S：96,000以上／A：80,000以上／B：55,000以上／C：25,000以上／D：それ未満。

使ったゴールドも獲得総額に含めます。タイムはゲーム内の進行時間で、選択・商店・地図・一時停止・ヒット停止を除きます。
「新しい旅」「同じ旅」「流派を選び直す」から再挑戦できます。同じ旅は敵配置と抽選に使う乱数列を再現します。進め方や選択が異なれば、その後の候補も変わり得ます。戦闘の完全リプレイではありません。
称号、記録、設定をlocalStorageへ保存します。途中の冒険のセーブはありません。保存が利用できなくてもゲームは動きます。

## 操作案内・音・演出設定

戦闘中はHP・MP・技・現在地を中心に表示し、詳細ログは折りたたみます。説明と装備の比較は休憩画面で確認できます。
開始画面／一時停止から、効果音と音楽の音量、画面揺れ・発光・ズームの軽減を設定できます。端末のreduced motion設定にも従います。音はブラウザ内で生成します。

## 検証

Node.js、Playwright 1.62.1、Chromiumを使用。サーバー起動後：

```sh
node tests/startup.cjs
node tests/rhythm.cjs
node tests/responsive.cjs
node tests/browser-smoke.cjs
node tests/terrain.cjs
node tests/progression.cjs
node tests/polish.cjs
node tests/experience.cjs
node tests/depth.cjs
node tests/journey.cjs
node tests/portability.cjs
# 回避しない移動・技の連打と比較
NAIVE_PLAY=1 node tests/journey.cjs
# 3組の旅番号 × 3流派
JOURNEY_ROUNDS=3 node tests/journey.cjs
```

`BASE_URL`（既定ポート8000）と`CHROMIUM_PATH`（既定 `/usr/bin/chromium`）を変更できます。
テストは戦闘・全技・成長・地形・増援・経済・保存・操作・画面サイズ・経路・通しプレイを確認します。
自動操作は回避タイミングなど内部状態を利用するため、人間の難易度や楽しさの証明にはなりません。
ヘッドレス描画の処理時間も実機スマートフォンのFPS保証ではありません。

変更と検証記録は `docs/IMPROVEMENT-LOG.md`、初見プレイの観察手順は `docs/PLAYTEST.md` を参照してください。

## 描画の負荷

地面は最大6チャンク、樹木は12種類の画像を再利用。画面外の立体物を描かず、隠れたUIは内容が変わったときだけ作り直します。歩行中の粒を減らし、技の魔法陣・斬撃・命中の閃光に描画を集中します。通行判定も再利用します。処理時間の測定結果と制限は `docs/IMPROVEMENT-LOG.md` を参照してください。
