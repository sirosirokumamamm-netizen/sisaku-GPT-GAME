# 王たちの再調整と鍛錬場

2026-10-23。配布用index.htmlはscripts/build.cjsから再生成。ユーザー所有のzipには変更していない。

## 戦闘

神の第1形態の障壁中は、ダメージ計算後の命中を1に固定。通常・手動技・自動技・継続ダメージ・必殺技に適用し、クリティカルや弱点による再増幅は行わない。障壁解除中は通常どおり。第2形態の障壁と詠唱バーは既存のルールを維持する。第1形態の障壁を4秒から3.3秒へ短縮し、青白い結界と固定1の表示、解除中の開いた金の光輪で区別する。既存の鏡エフェクトも残す。第2形態の瞳は主人公への方向を各眼の回転座標へ変換して追跡する。

神の攻撃は第1形態4種類、第2形態7種類を一巡する抽選にし、一巡の境目でも直前と同じ攻撃を繰り返さない。追尾雷は7発から3発へ短縮し、既に出ている予兆と次の攻撃が重なり続けないよう間隔を設ける。冥王のHPは6500→7300、基礎攻撃力は50→56。直線突進の狙いは発動0.32秒前に固定し、魔術・剣技の待機と着弾を短縮する。

荒野のボスを「忘却の王骸オルガルド」に変更。石の肋骨、浮遊する脊椎、角の仮面、二本の鎌、第二段階の浮遊刃を持つ専用モデルと6種類の攻撃を用意した。前モデルと同じ通常巨兵へ描画が流れないことも検証。HP13200、基礎攻撃力60。後に配置する影のボスはHP15500とし、影の通常敵と後半の増援も強化した。

## 進行と保存

表示順は旧ステージIDの `[0,1,2,3,4,5,7,6,8]`。セーブ内のクリア記録・武器の解放条件を数値の入れ替えで壊さない。新しい順序は天界→荒野→影→神殿。古いセーブで既に持っていた影・神殿の解放権は個別に保持する。

天界・荒野・影は通常5区画＋ボス。通常区画は天界が2〜3波、荒野が3波、影が3〜4波。古い5区画構成の中断保存は、現在位置と能力を維持して6区画構成へ移行する。神殿は従来の8連戦で、各決闘のクリアにつきポーション1個を支給。区画ごとの記録で同じ報酬の二重支給を防ぎ、最終決闘にも対応する。変身時の特別支給は維持。すべての神殿の敵はオーラをまとい、動きを減らす設定では密度を抑える。

## 鍛錬場

地図に独立した入口を追加し、準備画面からも往復できる。技巧石の強化とゴールドの持ち込み枠・金運強化を移動。購入品のよろずや、実績受取のミッションと役割を分けた。剣・必殺技・継承技は既存のオリジナルイラストを使い、装飾されたカード、選択中の金枠、大きな詳細イラスト、強化前→後の数値で表示する。

「基礎性能」の内容を対象ごとに記載。剣は攻撃力、必殺技は基礎威力、攻撃技は剣技／属性技の基礎威力、防御・回復技は耐久・HP回復量・持続時間、パッシブは各効果の増加量。技は持ち込んだときのLv.1を強化する。範囲・再使用時間など据え置きの項目は変化なしと明記する。最大＋5は維持。技巧石のクリア基本数を6・10・15・22・34・50・78・110・190へ増量し、費用は段階と対象の価格・役割で調整。例えば同じ＋1でも旅立ちの剣と始祖の剣、護りの技とダーククラッシュの必要数は異なる。

## 描画

視界と図形の交差を使い、完全に画面外のエフェクト、予兆、敵、弾、設置技、装飾、ダメージ文字を描かない。敵は並べ替え前にも除外する。パーティクルは視界に入らない位置での生成も抑制する。ダメージ判定・残り時間・攻撃の解決・増援は描画と独立して継続する。画面外から横切る直線や、視界を覆う全域攻撃は描画対象。必要な危険表示と安全地帯を消さない。

新地域で既存ボスが召喚する通常敵にも色を追加し、未定義色で描画ループが止まる問題を修正した。
