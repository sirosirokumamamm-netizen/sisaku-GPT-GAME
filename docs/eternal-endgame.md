# 荒野・時の神殿と技巧石

2026-10-22。単独で動くindex.htmlはscripts/build.cjsから生成。旧セーブのID・継承技・武器・財布・ランクを維持し、新しい在庫と技巧石の状態を追加した。ユーザー所有のzipファイルは変更していない。

## 追加仕様

- 荒野：天界のクリアで解放。通常5区画＋ボスで、通常敵を強化し、新ボスを追加。初クリア後の購入権は2本の剣、必殺技、開始時の護符。既存ステージの敵HPは下げない。
- 神殿：影の世界のクリアで解放。Lv.7と6回の事前選択から開始。歴代8組のボスを強化して連戦し、踏破回数に応じてHP補正が1.4倍から最大1.6倍まで上がる。途中のボス撃破では全体のクリアにならず、8区画目のボス撃破でランク→継承の順に進む。最終撃破後の成長選択は禁止。
- 神殿の挑戦中は保存中断とボス再挑戦を禁止。挑戦のIDを開始時に保存し、次の起動時に未決着の挑戦があれば敗北として終了する。最終結果の継承待ちデータは保持する。
- 技巧石：クリア基本数は現在の進行順で6・10・15・22・34・50・78・110・190。Sは1.4倍、Aは1.2倍。敗北でも到達区画に応じた少量を持ち帰る。同一挑戦の受取量を記録し、ボス再挑戦後は差分だけを追加する。
- 鍛錬：最大＋5。剣の攻撃力は＋3%／段階、必殺技の基礎威力は＋4%／段階、継承技の基礎性能は＋3%／段階。継承技は実際に持ち込んだものだけが強化され、ステージ内で新しく取った同種以外の技には適用しない。パッシブ・回復・防御技にも対応。Lvと＋は別のデータ。
- 魔王踏破後：出発時に技威力の段階を保存して基礎威力＋18%。通常技の過大な一撃を段階的に圧縮し、踏破前は上限1000、踏破後は1500。連撃・持続技は各命中ごとの上限。通常攻撃と必殺技はこの技上限の対象外。
- 回復薬：HPは最大HPの28〜43%を挑戦の乱数から抽選、最低18、最大HPを超えない。MPは40%。HP・MPがともに満タンなら個数と乱数を消費しない。
- 背水の一閃：HPが低いほど基礎倍率が上昇し、最大3倍。血契斬：最大HPの5%を切り上げ、上限12の自傷。HPが費用以下なら発動せず、溜めの取消はMPを返して自傷しない。自傷は敵の被弾回数には加えない。

## 検証

ローカルChromiumで行う。実機のiOS・Android、および公開URL上の直接プレイ検証とは区別する。

- `node tests/eternal-endgame.cjs`：新要素の回復率・自傷・威力段階・既存ボスHP・全8系統の追加攻撃の実ダメージ・全域攻撃の行動切替・購入と上限・二重受取・旧セーブ・神殿の6選択と8連戦・中断禁止・最終結果・再読み込み敗北。320／390px縦、844px横、1280pxの地図・準備・鍛錬・護符・剣売場。ブラウザの実行時エラーも監視。
- `node tests/sovereign-trials.cjs`：既存のランク、巨人の剣、ボス変身、術式破壊、状態異常、安全地帯、追跡とカメラ。
- `node tests/clear-flow.cjs`：成長の必須選択、区画間の移動、最終ボスからランク・継承への遷移と再読み込み。
- `node tests/combat-readability.cjs`：回復・クールダウン、左右配置、縦横、拡大したタップ判定、実際の二本指入力とスティックの中央復帰。
- `node tests/stage-journey.cjs`：固定乱数の操作ボットで3流派×9ステージ。敵への無条件即死や無敵化を使わず、警告からの回避・実際の技と必殺技・報酬の受取で進む。最高難度の神殿も8区画を通す。
- `node tests/startup.cjs`：通常・旧ブラウザ相当・JavaScriptなし・Canvasなし。
- `node scripts/build.cjs --check`、`git diff --check`：生成物の一致、差分の形式。

画面確認では、鍛錬と護符が古い自動ページ分割に入ってしまう問題、準備画面の追記が装備名の幅を奪う問題、紺色の護符カードで見出しが暗くなる問題を修正した。

実施結果：新要素390項目と追加画面の実タッチ操作、3流派×9ステージの全27件、起動4条件、区画進行、95項目のボス回帰、スマホ相当の二本指操作が通過。実行した試験で検出した問題は修正後に再確認した。全ての過去の回帰スクリプトを一括実行したという意味ではない。
