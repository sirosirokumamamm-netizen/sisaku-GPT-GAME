# ボス演出と挑戦前の装備画面

2026-10-23。登場・変身・本性解放・撃破に、溜めと解放が分かれる演出を追加。`src/boss-theatre.js`が描画だけを担当する。

- 獣は落下と爪跡、水のボスは水柱、竜は翼と炎、守護者は浮遊結晶。
- 魔王は黒紫の裂け目・黒炎・大きな剣閃。神は第一形態の単純な光輪から、変身時に翼と多重光輪へ変化。
- 影の大魔王は裂け目から残像が本体へ集束。古代の王は破片と剣閃、鉱山のボスは結晶で演出する。
- 変身・撃破でもカメラを対象に寄せる。画面端の幕、タイトルのスライド、解放時の光と剣閃を組み合わせ、演出中の操作ボタンは隠す。既存のスキップと演出短縮を維持する。
- 強い攻撃の新エフェクトは元の攻撃形状でクリップし、環状攻撃の安全地帯には描画しない。画面外は生成せず、同時最大6個（描画負荷検出時3個）。破片は画面内の格子上へ分散させる。
- 動きを減らす設定では跳躍・回転・残像・新しい戦闘破片を省略。点滅OFFでは追加の画面フラッシュを止める。戦闘用乱数・攻撃判定・予告時間には介入しない。

ボス扉は`src/boss-gate.js`で一画面に整理。現在の剣・必殺技・技1～3を押すと、同じ画面内の候補が切り替わる。イラスト付き候補から直接交換でき、他枠の技は交換元を表示する。HP・MP・ポーション、戻る・挑戦ボタンを固定表示。スマホ縦は本文をまとめてスクロールし、PC・横画面では現在装備と候補を並べる。装備の変更は既存どおり現在の挑戦へ適用し、交換による能力の重複加算や無料回復をしない。

## HP調整

悠久の時の神殿の第1～5刻（草原・水路・火山・遺跡・魔王）のボスHPを、従来の神殿補正後から1.35倍へ変更。遺跡の2体にも個別適用。神・荒野・影の神殿戦と通常ステージのHPは維持する。魔王の第二形態は既存の変身計算を引き継ぐ。

## 確認

`tests/boss-presentation.cjs`で9テーマ・各演出の途中フレームを描画し、描画前後のHPや位置が不変であること、安全地帯中心の透明ピクセル、画面外生成の抑制、同時数上限、演出軽減設定、神殿8戦のHP変更範囲を確認。

実タッチで武器・必殺技・技の交換、技枠の交換・解除、キャンセル後の再確認、ボス開始までを検証。表示確認は1280×800、390×844、320×568、568×320、844×390。PC・スマホ縦横の登場・変身と実攻撃の画像を目視確認する。既存の`expedition-services`と`startup`も実行する。

`index.html`は`scripts/build.cjs`から生成。ユーザー所有の`swordsman-game.zip`は変更しない。
