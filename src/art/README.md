# スキル専用イラスト

ゲーム用に新規生成したオリジナルの2Dイラストです。参考として提供された既存作品の画像は同梱・加工・転載していません。

5枚のWebPに、それぞれ3列×3行の独立したイラストを格納。`src/dark-fantasy.js` の `SKILL_ART_SHEETS` が、左上から行優先の順でスキルIDとコマを対応付けます。全43スキルは別のコマを使い、黎明の大剣・改にも専用の絵を割り当てています。最後の1コマは将来のスキル用の予備です。

- `blade.webp`：斬撃、突き、三連閃、抜刀、十字、飛翔、双刃、吸命
- `arcane.webp`：断罪、闇、黎明、盾、反射、回復、影渡り、精霊、剣気
- `elements.webp`：炎、氷、落雷、隕石、連鎖雷、竜巻、剣の雨、地裂、必殺強化
- `training.webp`：鍛錬、攻撃速度、射程、体力、鎧、会心、会心威力、勝利回復、属性
- `mastery.webp`：魔力循環、再使用、見切り、反撃、戦意の鎧、収集、チャージ、黎明・改、予備

`node scripts/build.cjs` がWebPをdata URLとしてCSSへ埋め込み、配布用 `index.html` を再生成します。実行時の画像通信は発生しません。元の生成画像の内容・寸法を保ち、WebPへ形式変換して保存しています。

`tests/skill-art.cjs` は全スキルの割り当て重複・欠落、埋め込み画像のデコード、7画面サイズでの全43スキルの初回・Lv.3表示、絵と技名の重なり、外部通信なしを検証します。
