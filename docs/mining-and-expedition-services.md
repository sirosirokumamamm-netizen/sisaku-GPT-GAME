# 鉱山・枠拡張・ボス前の支度

2026-10-23。既存mainから実装し、`scripts/build.cjs`で1ファイル版を生成。ユーザー所有のswordsman-game.zipは変更していない。

## よろずやと挑戦画面

持ち込み技の枠拡張を鍛錬場からよろずや「枠の拡張」へ移動。価格は2枠目1800 G、3枠目3600 G。挑戦画面の「＋ 枠を増やす ↗」は、持ち込み枠の購入画面へ直接移動する。購入後は同じ挑戦画面へ戻れ、追加した枠で技を選べる。

お守りも初期1枠、最大3枠。よろずやで2枠目1000 G、3枠目2200 Gを購入できる。お守り欄から対応する棚へ直接移動可能。各枠の選択で重複したお守りを選ぶと交換し、同じ効果を重ねて装備しない。所持済みのお守りと旧セーブの装備IDを保持して配列へ移行する。満枠時の購入・装備は、よろずやで交換するお守りを指定できる（2026-10-23のUI統合で改善）。

地図と挑戦画面の並びを、よろずや→鍛錬場→ミッションに変更。鉱山は独立した入口を追加。通常9ステージの順序とIDは変更しない。

## お守り12種類

以前の9種類に「勇気」「不動」「巡流」を追加。勇気は奇数区画開始から12秒間、攻撃力・属性威力を20%強化。不動はボス戦の最初の被弾5回を8軽減。巡流は奇数区画でMP25%・必殺ゲージ8を回復する。

発動機会の少なかった再起は、奇数区画でHP14%・MP10%を回復する形へ変更。既存の回復・異常防御・バリア・攻撃速度の効果も組み合わせられる。複数の固定ダメージ軽減を装備した場合は、大きい軽減値・多い回数を使用し、加算はしない。

区画開始で各お守りを1度だけ発動。鉱山では深度と区画を合わせた番号で管理し、次の深度の同じ区画でも正しく再発動する。増援・変身・保存の開き直しでは再発動しない。冒険開始時の組み合わせを中断記録にも保存する。

## ボス扉

最後の通常区画をクリアして扉に触れると、ボス名、現在のHP・MP・ポーション、剣、必殺技、3つのスロット技を一画面で確認できる。習得した技と所有する装備から変更し、「ボスに挑む」で次の区画へ進む。「まだ入らない」は扉の手前へ戻る。

装備変更は現在の冒険に適用。武器の威力・速度・間合いは差分で交換し、付け直しても能力を重複加算しない。HP・MPの無料全回復は行わない。神殿の次の決闘と鉱山の4区画目にも対応する。

## 技とボスの調整

- ダーククラッシュの基礎威力をLv.1〜3で300 / 460 / 720へ。黎明の大剣・改の同Lvの根元威力252 / 384 / 624を上回る単体技として調整。既存の1ヒット上限は維持。
- 血契斬は最大HPの8%を支払い、MP消費0。固定の反動上限は廃止。溜めの開始時と発動直前の両方でHPを確認し、反動以下のHPでは放てず、ボタンにもHP不足を表示する。溜めを中止すればHPを支払わず、発動時のHP不足でも反撃権を失わない。
- ジャスト回避のクールダウン短縮は残り時間の40%、1回につき最大2秒。完全リセットしない。反撃威力・MP回復・演出は維持する。
- 属性技の威力計算は属性威力と剣威力の65%の大きい方を基準とする。弱い属性技も剣の強化に追随する。固定だった出血・炎上・炎の撃破時の爆発も主人公の威力に連動する。
- 冥王HP7300→7150、忘却の王13200→12950。約2%の控えめな緩和で、既存の戦闘スタイルを維持。
- 神は第1形態6種類、第2形態10種類へ増加。連雷、神域を縦断する光柱、全域の輪と星の雨、追尾してから固定する星の崩落を追加。攻撃間隔も短縮する。第1形態は全体攻撃解決後に障壁解除、障壁中1ダメージ、解除時通常ダメージのルールを維持。

## 果てなき晶窟鉱山

火山クリアで解放する独立したステージ。通常ステージのIDを保持し、新ID9を使用する。4区画で1深度、最初の3区画が通常戦、4区画目が専用ボス。ボス後も次の深度へ続き、通常のクリア宝箱は出さない。

同深度内のHP増加は1区画ごと約3.5%。深度を上げる際は別の大きい倍率を加え、HP・攻撃力・増援数を強化する。岩壁、結晶、暗い洞窟の床を描き、木々の装飾は省く。専用ボスは「晶角の穿孔獣」「玄武岩の鉱王」「燐光の晶霊」の3種類で巡回し、それぞれ専用の形状と色を持つ。直線攻撃、結晶の崩落、近距離攻撃、安全地帯のある全域攻撃を使用する。

技巧石は区画クリアごとに確保し、撤退・敗北でも失わない。深度1の一巡は258石、深度2は396石、以降も増加する。ゴールドは通常の約55%の係数で抑える。深度と区画の通算番号を挑戦IDごとに保存し、同じ区画の報酬は重複しない。最高踏破深度を記録し、一度踏破した偶数深度のすべてから再挑戦可能。挑戦画面で偶数深度を入力して指定し、未踏破・奇数の指定は拒否する。

「砕晶の剣」「地脈の閃火」の2つは鉱山内の成長候補にのみ出現。通常ステージや通常の継承宝箱・技図鑑には混入しない。専用のオリジナルの結晶・地脈炎のイラストを用意。鉱山開始時には深度に応じて2〜12回の成長選択があり、深い開始位置でも技を整えられる。

休憩時に中断または帰還できる。深度ボスを倒した後の休憩も保存可能。再開時に深度・専用技・装備・確保した技巧石を復元し、同じ報酬を再配布しない。お金は帰還・敗北で一度だけ精算する。神殿の中断不可ルールは変更しない。

通常の技巧石報酬は全ステージで約3倍。草原から順に基本18 / 30 / 45 / 66 / 102 / 150 / 234 / 330 / 570石。ランク補正は従来どおり。以前の500石の保存上限も引き上げ、高難度報酬が切り捨てられないようにする。
