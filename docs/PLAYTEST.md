# 初見プレイの観察手順

実装・自動検証の次に行う人による評価。まだ実施していない。本人の同意を得た協力者5人程度に、PCとスマホを含めて試してもらう。

## 準備

- 初めて遊ぶ人には「舞台を選び、4区画を越えて5区画目のボスを倒すゲームです」と伝える。
- 操作・強化の正解を先回りして教えず、迷った場所を観察する。
- 記録するのは行動・感想。個人情報や無断の録画は不要。
- 端末・入力方法・舞台・区画・流派を控え、同じ条件で改善前後を比べる。

## 最初の60秒

| 観察項目 | 記録 |
| --- | --- |
| 説明なしで移動できた時点 | 秒数と迷った操作 |
| 最初の技を意図して使った時点 | キー／ボタンを見つけたか |
| 回避と敵の予告 | 赤い範囲と金色の瞬間を理解したか |
| 撃破の認識 | 生きている敵と倒した敵を見分けたか |
| 最初の4択 | 選択理由を本人の言葉で聞く |
| 画面の読みやすさ | HP、目的地、技の再使用に迷った箇所 |

## 1回の冒険

- 被弾後に理由が分かったか。盾・支援役・射手で行動を変えたか。
- 強化後に違いを実感したか。好きな組み合わせを挙げられたか。
- 増援が急すぎないか。ステージCLEARとボス撃破の区切りが分かったか。
- 出発準備のポーションに気づいたか。購入と使用チェック、次の挑戦での効果を理解したか。
- 2.5Dの障害物の見た目と通れる場所に食い違いを感じたか。
- タッチで移動しながら回避・技を押せたか。指で重要情報を隠したか。
- 重い場面、目が疲れる場面、音が不快な場面があったか。

## 宝箱と再挑戦

- 宝箱のレア技が永久解放で、次回一つ持ち込めることを説明なしで理解できたか。
- 区画間の成長維持と、舞台開始時の初期化を区別できたか。
- 4択の詳細を開く必要があったか。カードを読む時間と保留を使った理由を記録。
- 結果を見て次の舞台、同じ舞台、終了のどれを自発的に選んだか。
- 実時間と実戦時間を別々に記録し、前半2〜3分・後半3〜5分の設計目標と比較する。

## 終了後

1. 一番気持ちよかった具体的な瞬間はどこか。
2. やめたくなった具体的な瞬間はどこか。
3. 次に試したい育て方や行動はあるか。
4. 操作を促さず、自分から再挑戦するかを記録する。

感想を全員に平均して一度に大量変更しない。同じ箇所で複数人が迷った場合は優先し、最も大きな問題を一つ修正して再確認する。
自動テストの全通過を「完成度100」「人にとって面白い」と読み替えない。

## 拡張版で追加した確認観点（人の検証は未実施）

- 前哨戦、大群、精鋭、宝庫の違いを説明なしで認識できるか。金の冠を持つ敵を脅威として見分けられるか。
- 秘宝4択に迷いすぎず、次の区画の戦い方を想像できるか。取りたい候補がなくなる頻度。
- 休憩から先へ進むボタンを見つけられるか。スマホで装備・補給・中断にスクロールする負担。
- 中断時と再開時に、レベル・秘宝・回復購入・タイムが期待通りと感じるか。
- 草原の初見プレイ、火山・遺跡の慣れたプレイで、回復購入が救済として働くか。技を押し続けるだけで全戦闘が単調になっていないか。
