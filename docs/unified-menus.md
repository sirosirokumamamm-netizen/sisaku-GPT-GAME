# 支度画面のUI整理

2026-10-23。よろずやを共通ヘッダー・カテゴリ・本文・戻るボタンの一画面に統合。`src/storefront.js`が購入処理と表示をまとめ、従来の入口関数も同じ画面へ接続する。生成HTMLは`node scripts/build.cjs`で更新する。

- 「剣・秘伝書・お守り・枠拡張」を常に表示し、その場で内容を切り替える。カテゴリ間で商品選択と一覧スクロールを保持する。
- 戻る先は訪問元の地図または挑戦画面に統一。お守り棚→よろずや、枠拡張→よろずやのような中間階層は廃止。
- 持ち込み枠・お守り枠は二つの購入カードに集約。挑戦画面からのショートカットでは対象を強調し、狭い画面では見える位置へスクロール。上限時に同じ数値への強化や購入ボタンを出さない。
- お守りの購入・装備済み表示を分け、満枠時は交換するお守りを選べる。所有は維持し、再装備は無料。
- 一覧だけにかかっていた固定の高さ制限を撤去。広い画面では一覧と詳細の下端を揃え、スマホ縦では一覧＋簡潔な詳細、横では二列で表示する。
- 鍛錬場は「永続強化」と用途を明示。詳細と購入ボタンのスクロール領域を分け、購入・戻るを常に表示する。
- 不要な補足・同値比較・重複した装備済みボタンを除去。ミッションの空表示と詳細欄を縮め、挑戦画面の武器を既存イラストへ置換。ボス扉は装備・現在値・挑戦操作を中心に整理する。
- 商品価格・セール・強化費用・戦闘バランス・セーブ形式は維持。

## 確認

`tests/menu-ux.cjs`で購入、無料再装備、指定枠のお守り交換、上限・金欠・未解放商品の購入拒否、タブ切替時の位置保持、挑戦画面への直接復帰、キー操作、選択タブのコントラストを検証する。

表示確認は1920×870、1280×800、390×844、320×568、568×320、844×390。スクロール対象以外の主要ボタンの到達性、横はみ出し、一覧下端、重複ページ送り・不正文字列の有無を確認し、PC・スマホ縦横の画像も目視確認する。既存のお守り・鍛錬・支度テストも併用する。
