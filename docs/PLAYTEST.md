# 初見プレイの観察手順

実装・自動検証の次に行う人による評価。まだ実施していない。本人の同意を得た協力者5人程度に、PCとスマホを含めて試してもらう。

## 準備

- 初めて遊ぶ人には「北へ進み、最後のボスを倒すゲームです」と伝える。
- 操作・強化の正解を先回りして教えず、迷った場所を観察する。
- 記録するのは行動・感想。個人情報や無断の録画は不要。
- 端末・入力方法・旅の番号・流派を控え、同じ条件で改善前後を比べる。

## 最初の60秒

| 観察項目 | 記録 |
| --- | --- |
| 説明なしで移動できた時点 | 秒数と迷った操作 |
| 最初の技を意図して使った時点 | キー／ボタンを見つけたか |
| 回避と敵の予告 | 赤い範囲と金色の瞬間を理解したか |
| 撃破の認識 | 生きている敵と倒した敵を見分けたか |
| 最初の4択 | 選択理由を本人の言葉で聞く |
| 画面の読みやすさ | HP、目的地、技の再使用に迷った箇所 |

## 1回の冒険

- 被弾後に理由が分かったか。盾・支援役・射手で行動を変えたか。
- 強化後に違いを実感したか。好きな組み合わせを挙げられたか。
- 増援が急すぎないか。ステージCLEARとボス撃破の区切りが分かったか。
- ポーションと商店に気づいたか。在庫・所持上限・使用間隔を理解したか。
- 2.5Dの障害物の見た目と通れる場所に食い違いを感じたか。
- タッチで移動しながら回避・技を押せたか。指で重要情報を隠したか。
- 重い場面、目が疲れる場面、音が不快な場面があったか。

## 終了後

1. 一番気持ちよかった具体的な瞬間はどこか。
2. やめたくなった具体的な瞬間はどこか。
3. 次に試したい育て方や行動はあるか。
4. 操作を促さず、自分から再挑戦するかを記録する。

感想を全員に平均して一度に大量変更しない。同じ箇所で複数人が迷った場合は優先し、最も大きな問題を一つ修正して再確認する。
自動テストの全通過を「完成度100」「人にとって面白い」と読み替えない。
