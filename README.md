# 蒼刃の剣士 — 拡張版

隠し舞台を含む6つの舞台から一つを選び、配置が毎回変わる4区画を越えて、5区画目のボスと戦う2.5Dアクションローグライト。通常攻撃は自動。群れへ剣技を使い、短い回避から反撃します。技・回避・必殺技は戦闘中だけ使用でき、非戦闘時にはボタンが暗くなります。壁へ向かって動けない場合は回避できないので、壁沿いか離れる方向へステップしてください。

配布物は **index.html 1ファイル**。画像・音・CSS・JavaScriptを含み、実行時の外部通信やライブラリは不要です。

[公開ゲーム](https://sirosirokumamamm-netizen.github.io/sisaku-GPT-GAME/)

## 神話拡張の変更

巨大な四足竜、角を持つ獣、触手の怪物、異形の魔王第二形態、六翼と回転環を持つ神を個別描画。登場・変貌・大技のカットイン、持続する炎、位置が途中で固定される追尾予兆を追加しました。魔王の必殺技「終末の黒い太陽」は中央の安全地帯へ移動して対処します。天界の神は障壁中7秒／攻撃可能5秒、後半は8秒／4秒。雷撃・追尾・広域神罰を繰り出します。防御による通常の軽減は35%を上限にし、大技の危険性を残しています。

魔王撃破後の剣は冥王の黒刃（追加波動）、天穿つ槍剣（対ボス強化）、黎明の聖剣（MP・必殺ゲージ補助）。スマホでも9本を一覧から直接選べます。

## 遊び方

ワールドマップの目的地→持ち込み技を選択→「この装備で出発」。地図の金色の「剣の店」では、初期6本（魔王撃破後は9本）の一覧から剣を選ぶと詳細が切り替わります。装備中との性能比較とおすすめも確認できます。最初は難易度順に3つの舞台を表示し、挑戦できるのは草原のみ。クリアすると次の舞台が解放されます。3つとも制覇すると、発見演出とともに第4の舞台が現れます。4つともクリアすると、幻の第5舞台「闇の世界」が出現。魔王を倒すと第6舞台「天界」と新たな3本の剣が解放されます。解放した舞台はいつでも再挑戦できます。

| 舞台 | 地形・敵 | 第5区画のボス |
| --- | --- | --- |
| 陽だまりの草原 | 広い通路、岩、浅瀬。弱い群れを多めに、攻撃は少数ずつ | 翠角の森王。突進を石柱へ誘い反撃 |
| 翡翠の水路 | 川と橋、射手、盾、突進役。遮蔽物で射線を切る | 蒼潮の番人。扇状の弾、移動技と衝突後の隙 |
| 熾火の火山 | 岩場と炉、爆薬の樽、爆弾役 | 熔翼の古竜。跳躍・突進・扇状の炎弾 |
| 星霜の遺跡 | 石柱と結晶、射手・盾・支援役の混成 | 星核の守護者＋月影の守護獣の二体同時戦 |
| 闇の世界 | 紫の亀裂、結晶、混成部隊 | 冥王ヴァルガ。復活・巨大化後は猛攻8秒／核心露出5秒 |

足場・障害物の配置、出現位置、敵の編成は挑戦ごとに生成。中央の通路と出発地点は確保します。通常区画は二陣、画面内の敵が減ると増援。5区画目は「ボス出現！」の登場演出。遺跡では二体同時、他は一対一です。ボスはHP半分で本性を現し、跳躍・突進で戦場を使います。攻撃後には別の場所へ移動し、本性解放後の着地点には短時間の危険地帯が残ります。ボス区画の奥は、進入できない川で区切ります。

通常区画は「前哨戦」→「大群」→「宝庫」→「精鋭」の4つ。大群は数が多く倒しやすい敵、精鋭は各陣1体の冠をつけた強敵、宝庫は戦闘後の秘宝4択です。最後の少数になった射手などは近づくため、追い回す時間を短縮します。

新しい敵は、飛行・急降下するハーピー、突進するビートル、転移する亡霊。第1区画は弱い群れを中心に、HP・攻撃・速度を後半ほど強化。金色のスライムは第2区画以降の候補ごとに0.15%、1挑戦1体まで。HP12でどの攻撃も1ダメージ。金の軌跡を残して高速で走り、14秒で逃げ、撃破すると経験値120と80Gを追加します。

魔王の復活後は、無敵猛攻8秒と攻撃可能な5秒を交互に繰り返します。縦の炎は安全な通路を1本残し、巨大隕石は予告した位置に落下。横切る炎も加わり、猛攻中は回避へ集中する構成です。

前半は約2〜3分、後半は約3〜5分が設計目標。時間制限はありません。自動操作の通し検証はしていますが、人の初見クリア時間は未検証です。

## 成長・宝箱・保存

- 経験値がたまるとレベルアップし、ランダム4択。未習得の技・装備中の技・系統・上限を考慮します。「あとで選ぶ」で短時間保留でき、未選択数を画面に表示。
- 手動技は空き枠へ自動装備。満杯なら3枠から交換先を選び、交換せず習得だけすることも可能。自動4種と常時強化はスロット不要です。
- 通常区画を越えるたびにHP・MPを回復。残っている成長選択を済ませると装備確認が自動で開き、「準備完了」を押してから上の光る門へ歩き、境界を越えると次の区画の敵が出現します。戦闘後の成長選択は保留できません。区画間はレベルや技を引き継ぎます。休憩はHP・MP、手持ちの回復薬、装備変更、次へ進むボタンを一画面に集約。画面が短い場合はボタンでページ送りし、ホイール操作は不要です。装備変更時は選択位置を保持し、回復薬には使用後のHP・MPを表示します。
- 宝庫では8種の秘宝からランダム4択。手動技強化、MP循環、短い回避の再使用短縮、休憩回復、必殺ゲージ、弱った敵への追撃、開幕の盾、攻守のリスク交換。今回限り・スロット不要で、一つだけ選びます。
- 舞台のボスを倒すと特別な宝箱4択。22種のレア候補の解放、準備用品、資金を獲得。初回は地域の未解放秘技を最大2枠優先し、150Gを追加。再クリアも40Gを追加。解放状態と用途は「技の図鑑」で確認できます。
- 解放したレア技から一つを次の挑戦へ持ち込めます。前回の選択と流派を記憶。HP・MP・経験値・挑戦中の強化は舞台開始時に初期化します。
- 結果はスコア・ランク・タイム・撃破・獲得物と短いヒント。次へ強制移動せず、次の準備／再挑戦／舞台選択を選べます。購入で使った金額はスコアから引きません。

回復屋はありません。拾った回復薬を最大3個まで持ち、戦闘中も休憩中も使えます。旧版で購入した準備用品は購入価格分のゴールドへ返金されます。区画クリア時の自動回復は数値と演出で表示し、満タンを超えた分は回復量に含めません。

各区画全体に、回復薬の樽1個と爆薬の樽3個を分散配置。1回攻撃で中身が出現します。回復薬は近づいて回収し、3本まで保管してHキー／画面ボタンで戦闘中・休憩中に使用（HP35%・MP40%）。所持中はJ/K/Lの左に緑の「H・薬瓶×残数」を表示。3個所持中には上限通知が出て、取得できなかった薬は床に残ります。爆薬はプレイヤーや敵の攻撃で点火し、短い導火線の後に爆発、近くの爆薬に誘爆します。敵が近づくだけでは爆発しません。

ワールドマップの剣の店では、標準剣・速い細剣・大剣・炎剣・氷剣・雷の双剣の6種から購入・装備。購入は永久所持、次の出発から反映します。一撃・速度・射程と追加効果を比較できます。

進行はバージョン付きlocalStorageへ保存。解放・レア・所持金・準備用品・ベスト・設定は敗北しても残ります。宝箱は選ぶ前に保存し、再読み込みでも同じ4択を再開。選択確定と報酬・解放は一つの保存にまとめ、連打と再読込の二重取得を防ぎます。保存できない場合もメモリ内で遊べ、注意を表示します。保存は同じブラウザ・端末・URLに限られます。

区画クリア後、成長と秘宝の選択を済ませて「中断して保存」を押すと、レベル・技・秘宝・ルート・所持金・タイムを保存して舞台選択へ戻れます。同じブラウザで再開すると、その休憩から装備を確認して次へ進めます。戦闘途中の自動中断保存はありません。保存枠は1つで、新しい挑戦を始めると中断記録を置き換えます。保存失敗時は休憩を維持して知らせます。

## 操作と戦闘

| 操作 | PCの初期設定 | タッチ |
| --- | --- | --- |
| 移動 | WASD・矢印 | 左スティック／画面ドラッグ |
| 通常攻撃 | 届く敵へ自動 | 自動 |
| 装備技3枠 | J・K・L | 右の技ボタン |
| 回避 | Space長押しで繰り返し（Shiftも使用可） | 回避長押し |
| 必殺技 | Q | 必殺技ボタン |
| 拾った回復薬 | H（設定で変更可） | 回復ボタン。薬を持っている間に表示 |
| 成長・宝箱・秘宝4択 | 1〜4 | カードをタップ |
| 区画クリア後の装備確認 | クリア後に自動表示／休憩中はEnter | 次の区画へ |
| 一時停止 | P | 一時停止 |
| 操作と設定 | ?／一時停止から | 一時停止→操作と設定 |

回避は移動方向へ短くステップ。無敵が切れてから再使用まで隙があります。攻撃直前のジャスト回避で敵がスロー、MP回復、次の技は威力2倍・MP不要。盾は正面ダメージを10分の1にし、押し返されます。背後か攻撃直後を狙います。

予兆は薄い外周から範囲が広がり、満ちると発動。同時攻撃を制限し、弾道と面攻撃を描き分け、重要な輪郭を技の光より手前に描きます。必殺技は最初から別枠で所持。命中・撃破・見切りでゲージをため、専用カットイン後に青く覚醒。一定時間、与ダメージ・移動速度が上がり、被ダメージは半分です。

設定の「細かい設定」から冒険データを初期化できます。確認後、解放・所持品・記録・中断冒険を削除。音量と操作設定は残ります。

技ボタンは左からJ・K・Lの順でキーを大きく表示。スマホでは回避を一段上へ配置。

設定でキー割当、効果音・音楽、画面揺れ、閃光、ダメージ数字、粒子量、演出短縮を変更できます。フォーカスが外れると一時停止。途中終了は確認してから確定します。タイムは選択・休憩・一時停止を除きます。

## 開発・起動

編集は `src/`、配布は生成した `index.html`。Node.jsでビルドでき、アプリの依存パッケージはありません。

```sh
node scripts/build.cjs
python -m http.server 8000 --bind 127.0.0.1
```

| ファイル | 役割 |
| --- | --- |
| src/core.js | 戦闘、スキル、地形判定、成長、音 |
| src/refinement.js | 戦闘中の回復、初期化、新規敵と魔王の猛攻 |
| src/adventure.js | 剣・樽・徒歩進行・新ボス・魔王の復活 |
| src/interface.js | タブ・ページ送り・休憩画面 |
| src/journey-ui.js | 剣の選択・比較、マップ装飾、回復演出、戦闘操作の可否 |
| src/render.js | 2.5D、キャラクター、予兆、専用カットイン |
| src/campaign.js | 5舞台×5区画、ランダム生成、保存、宝箱、準備・結果 |
| src/expansion.js | 区画の役割、秘宝8種、中断復元、図鑑、舞台イラスト |
| src/input.js | キー、タッチ、起動 |
| src/template.html / style.css | 画面構造、レトロな青いUI |
| scripts/build.cjs | 単一HTMLへの統合と同期チェック |

## 検証

Node.js、Playwright、Chromium、ローカルHTTPサーバーが必要です。クラウド環境にはPlaywright 1.62.1、Chromium、Pythonが準備されています。手元にPlaywrightがない場合は開発環境へインストールしてください。アプリ実行には不要です。

```sh
node scripts/build.cjs --check
node scripts/test.cjs
node tests/stage-journey.cjs
# 神話拡張の集中検証・1構成で全6舞台を通す短縮検証
node tests/epic.cjs
QUICK=1 node tests/stage-journey.cjs
# 任意：現行キャンペーンの描画負荷を測り、docsへ記録
node scripts/measure-campaign.cjs
NOVICE=1 node tests/stage-journey.cjs
```

`node scripts/test.cjs --journeys` で通し検証も含められます。`BASE_URL`で試験対象を変更できます。Chromiumは標準で `/usr/bin/chromium`。主要テストは `CHROMIUM_PATH` に対応します。スクリーンショットは `/tmp/`。

休憩の実キー操作・購入プレビュー・装備フォーカス・終了確認・長押し誤選択は `comfort`。秘宝の効果・支払い・中断再開・破損セーブ・図鑑・狭幅UIは `expansion`。区画クリアの停止・Space回避・隠し舞台の出現は `clear-flow`。新しいプレイ経路の検証は `campaign`、`regions`、`campaign-usability`、`stage-journey`。既存の戦闘回帰テストは内部の旧進行用フィクスチャを使うため、それだけで新しい舞台選択を検証したとは扱いません。`journey.cjs`は新しい通しテストへの互換入口です。
